# Spaced Repetition Revision Planner

A single-page web app that generates a personalized revision schedule using spaced repetition — a memory-science technique for effective exam prep.

## How it works
Enter your subjects and their exam dates. The app automatically calculates revision checkpoints at 14, 7, 3, and 1 days before each exam, then displays a combined, sorted schedule across all your subjects.

## Tech stack
- HTML, CSS, JavaScript (no frameworks, no backend)
